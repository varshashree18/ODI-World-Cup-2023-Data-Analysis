# ODI-World-Cup-2023-Data-Analysis

## Project Overview
This project analyzes the ICC ODI World Cup 2023 dataset using Python and data analytics techniques. The project explores batting, bowling, team, match, and player performance.

## Objectives
- Analyze top-performing batsmen and bowlers.
- Identify top run scorers and wicket takers.
- Analyze players with the most fours and sixes.
- Calculate batting strike rates and bowling economy rates.
- Analyze team-wise match wins.
- Analyze venue-wise match distribution.
- Explore player roles and team squad composition.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
1. Top 10 Run Scorers
2. Top 10 Wicket Takers
3. Players with Most Sixes
4. Highest Strike Rate
5. Team-wise Match Wins
6. Venue-wise Number of Matches
7. Best Economy Rate Bowlers
8. Players with Most Fours
9. Player Role Distribution
10. Team-wise Player Distribution

## Key Insights
The project provides insights into player performance, bowling statistics, batting statistics, team success, and match distribution during the ICC ODI World Cup 2023.
